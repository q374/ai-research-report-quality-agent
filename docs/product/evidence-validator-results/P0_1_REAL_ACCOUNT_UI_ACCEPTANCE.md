# P0-1 实际账号界面验收

日期：2026-09-20
范围：当前 Docker 运行环境、实际本机登录会话、既有真实 T001 v3 对话
费用：新增模型调用 0，新增 API 费用 0 元

## 问题

代码与自动化测试已包含质量卡，但实际登录页面最初只显示研究报告，没有显示证据校验状态。

## 根因证据

1. 运行中前端容器已挂载当前项目 `frontend/src`，容器内能读取质量卡源码；
2. SQLite 已存在 T001 v3 对应的 `review_required` 校验记录；
3. 问题页面最初请求了 run 列表和消息，却没有继续请求 `evidence-validation`；
4. 前端容器已连续运行约 6 小时，开发运行实例没有正确加载新增页面逻辑；
5. 仅重启前端容器后，无需改代码或数据库，页面开始请求校验接口并正常显示质量卡。

结论：本次问题是前端开发运行实例缓存/热更新状态未同步，不是校验数据丢失、Gateway 故障或功能未实现。

## 实际操作

- 只重启 `deer-flow-frontend`；
- 未重启 Gateway；
- 未修改或清理 SQLite；
- 未发送聊天消息；
- 未点击人工确认、退回或拒绝；
- 未调用模型或外部搜索。
