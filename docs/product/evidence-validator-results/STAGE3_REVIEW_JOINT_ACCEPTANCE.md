## 验收范围

本次使用隔离临时配置、真实 Gateway、真实前端和独立 SQLite，验证人工复核核心链路；没有调用模型，也没有访问外部网页。

- 真实接口：run 列表、校验结果 GET、人工复核 POST；
- 真实持久化：`runs`、`threads_meta`、`evidence_validations`；
- 真实界面：聊天页质量卡与“确认通过”交互；
- 为避免创建模型运行，只有无关的聊天历史和 state 响应使用本地模拟数据；
- 身份使用 `DEER_FLOW_AUTH_DISABLED=1` 的本地合成管理员 `default`，不是实际账号登录验收。

测试记录明确标注为 `stage3-joint-*` 合成验收数据，不代表真实模型输出或真实用户数据。

## 联合验收发现并修复的问题

首次真实页面截图发现质量卡坐标为 `y=0`，被高度 48 像素的固定顶部栏遮挡。此前 mock E2E 只校验 DOM 文本存在，没有验证用户实际能否看到。

处理过程：

1. 先增加浏览器回归断言：质量卡 `y >= 48`；原代码实测失败，收到 `0`；
2. 给质量卡增加顶部安全间距并禁止 flex 压缩；
3. 单条回归由失败变为通过；真实联合验收位置变为 `y=48`；
4. 聊天历史整文件 Chromium 回归 14 项通过。
