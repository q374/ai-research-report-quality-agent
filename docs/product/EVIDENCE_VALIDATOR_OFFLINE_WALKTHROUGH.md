## 4. 发现的设计缺口

1. EV-03 需要保存页面原文摘录，否则无法执行否定性结论反查。
2. EV-04 需要 ResearchBrief 先声明必填维度，不能在报告生成后临时决定。
3. EV-06 必须基于最终展示文本计算，不能使用模型自报数字。
4. EV-07 需要定义 URL 规范化口径：去锚点、去跟踪参数、识别重定向和别名。
5. 仅靠规则不能判断所有语义支持关系；无法确定时必须进入人工复核。

## 5. 进入实现前的通过条件

- 产品负责人确认首版规则和严重级别。
- 确认 `ResearchBrief`、`Claim`、`EvidenceItem`、`ValidationFinding` 的最小字段。
- 确认 fail-closed：校验器异常时不得绕过。
- 确认首版只做离线确定性规则，不新增模型调用。

满足上述条件后，才进入阶段 A 原型；本走查本身不等于功能完成。
